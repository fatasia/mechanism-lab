# 机理实验室 · Mechanism Lab

面向设备健康算法研究与受控影子运行的 Python / TypeScript 工程，当前版本 0.4。

- 阀门机理与学习模型双证据候选，独立 ONNX 推理和同步适用域门控。
- 执行器、电机、轴承、视觉与退化实验，保留工况外失败和逐记录证据。
- 六页本地界面，连接实验、模型、告警、维修复核、点检和备件领退。
- 模型目录 Ed25519 签名、脱敏 JSON 请求日志、基础监控及 SQLite 独立快照备份。

## 开始

环境：已在 Windows、Python 3.12、Node 24 验证。按[安装与启动](code/README.md#启动)准备依赖，再运行：

```powershell
./code/run.ps1 serve
```

打开 <http://127.0.0.1:8765>。首次使用没有实验产物，需按安装说明训练基线；数据与模型不随源码分发。
