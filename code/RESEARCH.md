# 研究与发布约定

本工程用于设备异常检测实验。源码采用MIT许可证，见根目录LICENSE；数据、第三方权重与依赖分别保留原许可。

## 来源隔离

- 代码独立实现；不从供应商资料、专利文本或既有平台仓库复制实现、截图、图表和文案。
- 项目曾参考外部产品方案和公开专利，不能标注为洁净室开发。
- 私有参考资料、专利草稿和过程文件位于代码目录之外，受根目录 Git 忽略规则管理。
- Git 忽略不等于发布许可审核；发布前检查实际暂存区、历史和打包文件。

## 数据和算法归属

- UCI Hydraulic Systems：官方来源 https://archive.ics.uci.edu/dataset/447/condition+monitoring+of+hydraulic+systems ，CC BY 4.0，DOI 10.24432/C5CW21。下载数据保持在 data，保留原始出处；转换和切分记录为本项目处理步骤。
- 卷积、自编码器、孤立森林、稳健统计、TCN 均为已有方法，不作为本项目独创算法描述。
- 数据版本、下载哈希、标签映射、训练/验证/测试切分、随机种子和运行环境随实验保存。
- 合成测试夹具只验证代码行为，不用于宣称真实设备性能。

## 实验与贡献

每项新增设计分别记录：已有方法、具体改动、要检验的假设、对照、失败案例和实际结果。测试集不参与阈值选择。模型效果、ONNX 数值一致性、现场验证分别报告。

论文引用应指向实际阅读的来源；不生成不存在的实验、数据或引用。专利候选只记录实际设计与发明人贡献，是否具备新颖性另行检索判断。

## 发布前检查

1. 确认可公开的技术范围，专利草稿不自动发布。
2. 源码许可证已确定为MIT；继续核对具体依赖和分发包的许可及NOTICE要求。
3. 检查代码、测试、文档、Git 历史与压缩包中是否混入私有资料、密钥、原始数据或第三方素材。
4. 提供依赖锁定、来源清单和复现实验步骤；未运行的实验标记为未执行。
5. 演示 UI 独立绘制，不使用供应商标识、截图和私有数据。

0.4 扩展加入了原版 MiniRocket / MultiRocket 强基线、独立实现的 CNN 及 ONNX 数值映射、冻结 ResNet18 表征和正常 patch 记忆、寿命回归与区间校准。均按已有方法或实际改动署名，不作为原创基础算法。视觉演示仅使用 CC BY 4.0 的 VisA 图像，公开来源和第三方声明见 SOURCES.md / THIRD_PARTY_NOTICES.md。新工况失败、视觉漏检及延后检出保留在报告中。
