# 公开数据阶段交付清单

目标：可复现、可试点的部件级 PHM 软件。对标能力，不把厂商宣传指标当作共同测试标准。只使用发布方公开数据；既有测试结果归入开发证据。

| 优先级 | 任务 | 验收要求 | 状态 |
|---|---|---|---|
| P0 | 独立 CARE 测试集 | 排除已查看设备、冻结规则和哈希；只作一次最终评价 | 已完成9例；设备不足不重复旧资产 |
| P0 | 预警方法比较 | 固定源校准、正常告警负担、机会基线及设备级统计 | 已完成；三个方法未优于机会水平 |
| P0 | 长稳与恢复 | 72 小时实测；中断不得记为通过 | 72小时运行中；短时重启/备份预检通过 |
| P1 | 工况识别与有限参考 | 目标故障不调参；覆盖率和全分母指标 | 执行器实验完成、未通过整体准入；电机健康参考不足 |
| P1 | 流式接入 | 校验顺序/时间/单位；断连重试、幂等、离线一致 | JSONL持久队列与HTTP重试通过；不是实机协议驱动 |
| P1 | 极片质量研究 | 消融、学习曲线、区间、工艺外拒识，非设备 PHM | 已完成；区间可靠性未达标 |
| P1 | 维修证据流程 | 输入/版本/告警/人工确认可追踪，未知不变真值 | 证据API及页面通过；含版本、摘要、人工复核 |
| P2 | 部署与安全 | CI、依赖锁、TLS、权限、密钥轮换与恢复检查 | 本机TLS/接入账号ACL/轮换通过；远端Windows测试与Ubuntu前端构建通过，提交见验收记录 |
| P2 | 多模态与资料检索 | 仅真实配对证据支持融合；资料回答有来源 | 白名单资料检索完成；无合格新配对证据，不追加融合模型 |

现场锂电数据、维修真值、真实 PLC 验收、生产收益和同场供应商比较均不在公开数据可验证范围内。运行中与已通过分开记录，失败实验也属于交付，不伪造算法达标。

详细结果、命令和范围见[公开数据试点包](PUBLIC_PILOT.md)。完整运维多租户、SSO、PostgreSQL和目标硬件部署没有因基础权限/TLS完成而自动完成。
