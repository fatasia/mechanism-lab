# 公开数据阶段交付清单

目标：可复现、可试点的部件级 PHM 软件。对标能力，不把厂商宣传指标当作共同测试标准。只使用发布方公开数据；既有测试结果归入开发证据。

| 优先级 | 任务 | 验收要求 | 状态 |
|---|---|---|---|
| P0 | 独立 CARE 测试集 | 排除已查看设备、冻结规则和哈希；只作一次最终评价 | 进行中 |
| P0 | 预警方法比较 | 固定源校准、正常告警负担、机会基线及设备级统计 | 进行中 |
| P0 | 长稳与恢复 | 72 小时实测；中断不得记为通过 | 待启动 |
| P1 | 工况识别与有限参考 | 目标故障不调参；覆盖率和全分母指标 | 待做 |
| P1 | 流式接入 | 校验顺序/时间/单位；断连重试、幂等、离线一致 | 待做 |
| P1 | 极片质量研究 | 消融、学习曲线、区间、工艺外拒识，非设备 PHM | 待做 |
| P1 | 维修证据流程 | 输入/版本/告警/人工确认可追踪，未知不变真值 | 待做 |
| P2 | 部署与安全 | CI、依赖锁、TLS、权限、密钥轮换与恢复检查 | 待做 |
| P2 | 多模态与资料检索 | 仅真实配对证据支持融合；资料回答有来源 | 待评估 |

现场锂电数据、维修真值、真实 PLC 验收、生产收益和同场供应商比较均不在公开数据可验证范围内。运行中与已通过分开记录，失败实验也属于交付，不伪造算法达标。
